# SCALE X — GitHub Pages Website

A responsive, static website for SCALE X — Creative Growth Studio. It uses HTML, CSS, and a small JavaScript file. No build tools, package installs, or server required.

## Files
- `index.html` — complete website content and sections
- `styles.css` — responsive black, white, and orange design
- `script.js` — mobile menu and current year
- `assets/favicon.svg` — browser icon

## Publish on GitHub Pages (free)
1. Sign in to GitHub and create a **new public repository**. Suggested name: `scalexstudio.github.io` if your GitHub username is `scalexstudio`; otherwise use any repository name, e.g. `scalex-website`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository's **root**. Upload the `assets` folder too, keeping `favicon.svg` inside it.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish publishing. The website URL will be shown in Settings → Pages. For a normal repository it usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before you share it
- Test the published website on mobile and desktop.
- Confirm the email and Instagram links are correct.
- Follower numbers are shown as targets only, not guarantees.
- The website is static. The contact buttons open the visitor's email app; there is no database or form backend.
- Google Fonts loads from Google; if blocked, system fonts are used as fallback.
- GitHub Pages hosting is free for public repositories, subject to GitHub's current terms and limits.

## Updating the website
Edit the relevant file in GitHub and commit the changes. Pages will republish automatically after a short delay.
