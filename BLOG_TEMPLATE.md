# New SCALE X blog template

To publish a new blog, create a Markdown file inside `_posts/` with a filename like `2026-10-25-instagram-reels-tips.md`. Copy this template into it and replace the sample text. The Blogs page will list it automatically and Jekyll will create its own article URL.

```markdown
---
layout: post
title: "Your Blog Title"
description: "One-sentence summary for the blog listing and search results."
category: "Instagram strategy"
date: 2026-10-25
author: "SCALE X"
---

Write your introduction here.

## First heading

Write your paragraph here.

## Second heading

Write another paragraph here.
```

Important: filename starts with `YYYY-MM-DD-`; use `.md`; keep the front matter between the first two `---` lines. After committing, GitHub Pages builds the blog and adds it to `blogs.html` automatically. To edit an existing article, edit only that article's Markdown file inside `_posts/`.
